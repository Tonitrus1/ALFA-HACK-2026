# Готовый набор: 10 000 компаний, синтетическая отчётность

Создан 21 октября 2026 года по времени Asia/Yekaterinburg. Времена машинных
журналов — UTC. По просьбе пользователя ГИР БО заменён искусственными суммами.

**Данные уже сгенерированы и проверены. Для открытия файлов запускать сборщик
и скачивать выгрузки ФНС заново не нужно.**

## Какой файл использовать

| Файл | Строк | Реальные данные | Искусственные данные | Метки банкротства |
|---|---:|---|---|---|
| `registry_companies_real.parquet` / `.csv` | 10 000 | ИНН, ОГРН, название, МСП, ОКВЭД, регион | Нет | Отсутствуют |
| `hybrid_real_msps_synthetic_financials.parquet` / `.csv` | 10 000 | Реквизиты выбранных ООО | Все финансовые суммы | Все null: реальные исходы не подтверждены |
| `training_simulation.parquet` / `.csv` | 10 000 | Нет настоящих идентификаторов компаний | Компании SIM, финансы, даты и классы | Искусственные 0/1: 512 единиц, 9488 нулей |

**Для технического обучения используйте `training_simulation.parquet`.**
Настоящим компаниям не приписаны вымышленные банкротства. В гибридной таблице
синтетические суммы также не являются сведениями о финансовом состоянии этих ООО.
Набор проверяет работу загрузки/обучения/метрик, а не качество реального прогноза.
Банкротство, тем более искусственное, не является банковским кредитным дефолтом.

Готовое разбиение полностью синтетического набора:

| Часть | Файл | Строк | Единиц |
|---|---|---:|---:|
| Train | `simulation_splits/train.parquet` | 7016 | 352 |

ID компаний между частями не пересекаются. Доля класса около 5% выбрана как
параметр симуляции и не описывает российскую популяцию МСП.

## Быстро открыть

```python
import pyarrow.parquet as pq

train = pq.read_table("simulation_splits/train.parquet")
features = [
    "total_assets", "current_assets", "total_liabilities",
    "current_liabilities", "equity", "revenue", "net_profit",
]
X = train.select(features)
y = train.column("target_12m")
print(train.num_rows, X.schema, y.to_pylist()[:10])
```

Зависимость: `python -m pip install pyarrow`. Для pandas/scikit-learn можно
конвертировать значения в числовую матрицу в своём эксперименте. CSV сохранены
в UTF-8 с BOM для удобного открытия; ИНН/ОГРН нужно читать текстом, без float.
Parquet сохраняет идентификаторы строками и суммы точно в decimal128(28,2).

Не используйте в признаках `company_id`, ИНН/ОГРН/название, `target_12m`,
`label_status`, `label_source`, `event_date`, `observation_end_date`, `split`.
`simulation_truth_DO_NOT_USE_AS_FEATURES.parquet` содержит истинную вероятность
**генератора** только для диагностики; подмешивание её в X создаст утечку.
Предпочтительный список признаков и описание всех колонок — в `data_dictionary.json`.

## Финансовая симуляция

Год отчётности — 2025, условная дата оценки — 21.10.2026, горизонт — до 21.10.2027.
Даты будущих событий присутствуют только в полностью вымышленной симуляции.
`simulated_available_at` — вымышленная дата, не подтверждённая публикация ФНС.

Все денежные поля — рубли, два десятичных знака. Баланс согласован до копейки:

- активы = капитал + все обязательства;
- обязательства = долгосрочные + краткосрочные;
- активы = внеоборотные + оборотные;
- оборотные = деньги + дебиторская задолженность + запасы + прочие;
- чистая прибыль = EBIT − проценты + прочий результат − искусственная налоговая нагрузка.

В наборе есть 3228 искусственных убыточных компаний, 985 строк с отрицательным
искусственным капиталом и 137 с нулевой искусственной выручкой. Это свойства
генератора, не статистика настоящих ООО. Пропуски реальных исходов не заменены нулями.

Seed=20261021. Сначала генерируются финансовые значения, затем вероятность
события зависит от долговой нагрузки, рентабельности, ликвидности и знака капитала.
После этого класс рисуется случайно. Средняя вероятность калибруется к условным
5%; финансы не генерируются условно на заранее назначенном классе. Суммы не
подогнаны под реальные известные банкротства. Формула и исходники — в обновлённом
проекте `ru-sme-bankruptcy`, документ `docs/SYNTHETIC_MODE.md`.

## Откуда реальные компании

[Официальный реестр МСП ФНС](https://www.nalog.gov.ru/opendata/7707329152-rsmp/),
срез 10.10.2026. Выбраны только ООО с основным ОКВЭД2 вне разделов 64–66.
Выборка охватывает 88 региональных кодов ФНС и 80 разделов основного ОКВЭД.
Исходные категории: код 1 — 8957 компаний, код 2 — 1005, код 3 — 38.
Коммерческая форма отобрана по буквальному полному наименованию ООО в реестре,
а не по отдельной выписке ЕГРЮЛ. Специальные финансовые организации с другим
основным ОКВЭД могут требовать дополнительной проверки.

Полный ZIP получить не удалось: соединение обрывалось, безопасная докачка без
валидатора не была доступна. Использованы только 1920 целых XML-member из
полученного префикса 569 376 768 байт; каждый проверен по CRC32 и размеру.
Из 493 714 подходящих уникальных ООО в восстановленной части отобраны 10 000
минимальных SHA256(`research-v1:ИНН`). Неполный последний member отброшен.
**Это выборка из восстановленного фрагмента, не репрезентативная выборка всего
реестра.** Текущее членство в МСП не доказывает историческое членство ранее среза.

`raw/rsmp_selected_documents.xml` содержит 10 000 выбранных корпоративных
документов в исходном текстовом представлении с добавленной общей XML-обёрткой.
Документы ИП/физлиц не включены. Все индивидуальные SHA-256 проверены против
`source_document_sha256` в таблице реестра. ФНС требует сохранять ссылку на источник
и достоверно представлять исходные открытые сведения; здесь реестр и вымышленные
суммы явно разделены. Нельзя распространять эти суммы как официальную отчётность.

## Проверка и воспроизведение

`validation_report.json`: проверены 10 000 уникальных ИНН и ОГРН с контрольными
цифрами, 10 000 хэшей исходных XML-документов, балансовые равенства на всех
20 000 строках двух таблиц, отсутствие пересечений split, корректность горизонта,
маркировка синтетики и отсутствие искусственных классов у настоящих ИНН.
`generation_report.json` хранит параметры, количества и SHA-256 файлов.
Независимая повторная проверка: `python verify_dataset.py` (нужен только pyarrow).
`registry_provenance.json` — границы выборки и источник. `MANIFEST.sha256` — все файлы.

Для повторения с тем же реестром и seed в обновлённых исходниках проекта:

```bash
python -m sme_data generate-hybrid \
  --registry /path/to/registry_companies_real.parquet \
  --output /path/to/new-generated-data \
  --seed 20261021 --report-year 2025 --as-of 2026-10-21
```

Внешние источники при этом не запрашиваются. Реальные отчёты ГИР БО в эти суммы
не подмешаны. Подтверждённые настоящие судебные исходы в данной поставке отсутствуют.
