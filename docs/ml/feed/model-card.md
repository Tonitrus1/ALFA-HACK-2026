# Модель рекомендаций и качество

> Обновление 22.10.2026: каталог v2 на 72 карточки, синтетические события и экспериментальный CatBoost описаны в [текущей поставке](hackathon.md). Разделы ниже сохраняют описание E5 MVP и исторические проверки; новые результаты находятся в `reports/hackathon/`. [Контракт аналитического экспорта](analytics-contract.md).

Назначение: модель рекомендаций и качество.

Статус реализации: отдельный локальный ML-сервис; публичный backend и frontend не поставляются. Статус проверки документации — в [verification.md](verification.md).

Актуальность: 22.10.2026. Исходный проверяемый снимок: `ml/feed-recommendations` / [`829c1c09bb24`](https://github.com/Tonitrus1/ALFA-HACK-2026/commit/829c1c09bb248f03d730f25526de3b11712370bd). Среда исторических runtime-проверок: macOS arm64, Python 3.12.13. При этой миграции сервисы повторно не запускались.

## Назначение и допустимое использование

Упорядочивание разрешённых информационных карточек финансирования бизнеса по типизированному профилю. Не выдаёт кредитный продукт, решение или вероятность полезности. Персональная финансовая информация и свободный текст в API не принимаются.

## Активные компоненты

Локальная `intfloat/multilingual-e5-small`, revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`, источник — [карточка закреплённой модели](https://huggingface.co/intfloat/multilingual-e5-small/tree/614241f622f53c4eeff9890bdc4f31cfecc418b3); в её YAML заявлена MIT. [Model lock](../../../ml/feed/model-lock.json), [release manifest](../../../ml/feed/release/manifest.json), [runtime hashes](../../../ml/feed/release/SHA256SUMS). Полные большие веса — `.local/feed-bundle/model/`, не Git. E5 использует собственный tokenizer из той же ревизии.

CPU float32, 384 измерения, максимум 512 токенов, mean pooling с attention mask, L2-нормализация. `query: ` и `passage: `; passage = title + newline + text без дописанных metadata. Локальные PyTorch/Transformers загружают только проверенные файлы. [Notices](THIRD_PARTY_NOTICES.md).

Правила — отдельный не обученный компонент: ограниченные бонусы тем/глубины и diversification. Калибровки similarity нет. Rule fallback не выдаётся за результат E5.

## Данные и способ использования

Дообучения E5 нет; train/validation/test для неё здесь не создаются. Каталог — 36 собственных русских карточек, review и шесть SVG. Сценарии заданы отдельно. Нет обучения на реакциях; backend передаёт агрегаты последней реакции, ML использует фиксированные бонусы. Подготовка вычисляет только векторы каталога.

## Метод оценки и критерий выпуска

Пять заранее записанных профилей: ожидаемые темы в первой тройке; диагностические перефразировки и проверка изменения порядка по реакциям. Прогретая задержка измерена 30 последовательными запросами, 36 candidates, CPU/4 потока. Порог сценарного CLI — warm p95≤2000 мс. Это технический MVP-критерий, не банковское утверждение и не измерение полезности. RULES реализован, но контролируемого исследования superiority над ним нет.

## Результаты

Исторический [feed-evaluation.json](../../../reports/feed-evaluation.json), выпуск `feed-e5-v1-d068f7fcb894`, catalogDigest `20a2e621ecfaa6172ac6d222967ed86cbc097b7bd372699dea9b674aa98bce2f`. Пять основных сценариев прошли проверку ожидаемых тем; перефразировки проверяют хотя бы одну релевантную тему, не обязательное сохранение всех тем. На macOS14.5/arm64, 30 тёплых измерений: p50=19.98 мс, p95=26.79 мс, max=38.81 мс. Холодный startup, HTTP overhead и конкурентная нагрузка этим измерением не покрыты. При этой миграции latency и метрики не переизмерялись.

## Ограничения и непроверенные свойства

Перефразировка «закупка + стоимость» может вытеснить вторую тему из top3. Нет реальных пользовательских меток, A/B, причинного эффекта реакций, оценки банковской пригодности и пользы на неизвестных профилях. Контент просматривал исполнитель, человеческое банковское согласование не заявляется. Нет внешней LLM и динамического сочинения ставок/обещаний одобрения.
