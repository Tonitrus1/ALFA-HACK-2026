## Воспроизведение

Сначала [setup](setup.md). Команды ниже — инструкция будущего прогона, не описание выполненного сейчас. Зависимости/артефакты готовятся с сетью; обычный runtime локальный, платных API нет. Unit/API модельные тесты используют подготовленный локальный bundle; evaluate обновляет отчёт оценки.

ОС/оболочка: macOS arm64, POSIX shell. Рабочий каталог: корень соответствующей ветки репозитория.

```sh
./scripts/feed test --with-model
./scripts/feed evaluate
```

Ожидается успешный exit code, 58 тестов с --with-model; без флага real-model проверки могут быть SKIPPED. При иной версии зависимостей/снимка число тестов не объявляйте заранее как выполненный PASS.
