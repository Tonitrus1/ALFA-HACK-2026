### Исправления контракта до текущей поставки

FEED использует X-Service-Token; runtime OpenAPI описывает ServiceIdentity, безопасный MLError для 403/409/422/503, Cache-Control и Retry-After для 503. Idempotency-Key равен requestId. Входящий RankingResult требует явный scope=FEED, reasonCategory длиной 1–128, уникальные rankedIds и explanations с тем же набором ID. Backend также проверяет точное совпадение ответа с исходным запросом. Публичная спецификация 1.4.1-design содержит 63 операции. Это контракт, а не заявление о реализации публичных endpoints.

Для обычной ленты повтор cursor сохраняет контент/порядок/exposure/nextCursor, исключает скрытое без замены и обновляет userReaction из текущего состояния. Это явно разрешённые отличия снимка; helper replay_page принимает актуальные hidden и reactions. У полезного другая политика: изменение состава сохранений инвалидирует cursor по savedVersion.

Эти исправления уже присутствуют в исходном снимке; миграция документации не меняет их повторно.
