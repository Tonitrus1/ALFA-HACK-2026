## Невыполненные проверки

Новая установка зависимостей, запуск сервиса/БД, переобучение, горячее переключение, backup/restore, Docker/Linux/Windows и end-to-end UI. Для документационной правки они не запускались; отдельные исторические протоколы нельзя считать подтверждением этих способов deployment.

## Воспроизведение

Сначала [setup](setup.md). Команды ниже — инструкция будущего прогона, не описание выполненного сейчас. Зависимости/артефакты готовятся с сетью; обычный runtime локальный, платных API нет. Сценарии/serving tests добавляют synthetic records; runtime verifier перезапускает выделенный стенд и моделирует отказ БД.

ОС/оболочка: macOS arm64, POSIX shell. Рабочий каталог: корень соответствующей ветки репозитория.

```sh
./scripts/demo scenarios
./scripts/demo test
PYTHONPATH=ml .venv/bin/python scripts/verify_ml_runtime.py
```

Ожидается успешный exit code, 14 тестов исходного набора при рабочем стенде; результаты сценариев/проверок смотреть в reports. При иной версии зависимостей/снимка число тестов не объявляйте заранее как выполненный PASS.
