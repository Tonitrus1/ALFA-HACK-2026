# Документация ML-сервисов

Назначение: единая навигация и правила для документации. Статус: оформление версии 1.0. Актуальность: 22.10.2026; `ml/feed-recommendations`, код `829c1c09bb248f03d730f25526de3b11712370bd`. Проверенная среда исходного сервиса: macOS arm64/Python 3.12.13; переносимость на другие среды не утверждается.

## Сервисы

- Скоринг — [отдельная ветка](https://github.com/Tonitrus1/ALFA-HACK-2026/tree/ml/local-scoring-runtime).
- Рекомендации — [локальный README](../../ml/feed/README.md), [документация](feed/integration.md).
- Ассистент — [assistant-service](https://github.com/Tonitrus1/ALFA-HACK-2026/tree/assistant-service). Его файлы и ветка не изменяются; фиктивная локальная документация не создаётся.

## Порядок чтения

README сервиса → setup → integration. Отдельно architecture, model-card, data, operations, verification, THIRD_PARTY_NOTICES и CHANGELOG. Реализация и результат её проверки указаны раздельно. Исторические JSON/XML остаются на исходных путях, новый PASS без прогона не заявляется.

## Правила

Применён [переданный стандарт 1.0](DOCUMENTATION-STANDARD.md). Основной язык русский; H1 один; разделы H2/H3 без ручных номеров. Перед командами указаны ОС/оболочка/рабочий каталог и эффект. Секреты в примерах отсутствуют. Код, runtime OpenAPI, manifests, подписанные model cards и reports не переписываются ради формата. Общая [архитектура](../architecture/README.md) сохраняет роль спецификации.

## Источники и границы

Документы относятся к коду `829c1c09bb248f03d730f25526de3b11712370bd`, а не автоматически к более поздней интеграционной ветке, упомянутой в сравнительном стандарте. Старые handoff-пути ведут в центральную документацию. В этой ветке нет локального docs/ml для отсутствующих сервисов: используйте ссылки на их ветки.
