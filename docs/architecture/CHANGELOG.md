- Target-only трактовка отменена: 13 способностей полного стека, порты, владельцы, локальные заменители и настоящие адаптеры описаны в общем каталоге.
- Три профиля с валидируемыми bindings; никакого скрытого переключения authority. Каркас неготового SDK-адаптера явно отклоняет выбор.

- 25 обязательных задач MVP:112 человеко-часов, с резервом25%:140; дополнительная P27:8 часов; отдельный bank-target не оценён. 43 будущих сценария приёмки.
- Public/internal/demo wire API1.4.0-design сохранены без изменений; документационная версия1.5 отдельна от wire-версии.
- Предыдущий полный архив1.4 сохранён в соседней папке architecture-revisions; hash записан в evidence/revision-history.json. Исходные302 файла неизменны.
- Исполняемые сервисы, SDK-адаптеры, модели и runtime-тесты этим изменением не создаются.

# Изменения HACKATHON-1.4

20 октября 2026 года. Новая согласованная спецификация заменяет исторические пакеты, которые сохранены неизменными.

- Объединены четыре пакета; принят public OpenAPI1.4:60 операций и отдельный demo API.
- Внутренний ML-контракт согласован с банковскими пакетами, добавлены immutable finance inputs, snapshot read и RAG answers.
- CPU-first runtime отделён от целевой MLOps-платформы. Реальные4 ML-функции сохранены.
- Уточнены состояния/владельцы/роли, финансовые версии, RFI, документы, модельная семантика и revocation fence.
- Подготовлены24 задачи,37 runtime acceptance-сценариев,12 групп требований, Git/жюри-регламент и шаблоны поставки.
- Архивированы302 исходных файла;30 прошлых замечаний пересмотрены;3 испорченных сохранённых fixture восстановлены с журналом.
- Добавлена самодостаточная детерминированная сборка, статическая проверка и визуальный протокол.

## Реестр исправлений

- H01 [P1] ML-расширение не применено к базовым пакетам.
- H02 [P1] Финансовый снимок не входит в банковский пакет.
- H03 [P1] Две несовместимые активные границы скоринга.
- H04 [P1] Для RAG не описан внутренний HTTP-контракт.
- H05 [P1] Модель не имеет контрактного чтения feature snapshot.
- H06 [P1] Вход ранжирования не содержит текстов кандидатов.
- H07 [P2] Exposure metadata необязательна в ответах.
- H08 [P1] Схема допускает неподдержанные стандарты отчётности.
- H09 [P1] Отсутствует обязательная финансовая версия для выбранного MVP.
- H10 [P1] MVP требует Linux/NVIDIA и распределённые ML-хранилища.
- H11 [P1] Модели генерации и embeddings не выбраны.
- H12 [P2] Неподтверждённый ranking deadline 150 мс.
- H13 [P1] Базовый UI ориентирован на один продукт и не включает ML-путь.
- H14 [P2] Реестры не учитывают время и численность команды.
- H15 [P2] Полный canary требует недоступного объёма трафика.
- H16 [P1] Прежний общий валидатор не включает ML-пакет.
- H17 [P2] Повторная сборка требует соседний исторический пакет.
- H18 [P2] Не определён единый регламент Git и фиксации сдачи.
- H19 [P2] Результаты статических проверок требуют новой области доказательств.
- H20 [P1] Три сохранённых примера прежнего аудита не соответствуют ожидаемой валидности.

Приложение, runtime models, load/security/DR tests, публикация и отправка жюри не выполнялись.
