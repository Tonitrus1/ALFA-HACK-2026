# Компоненты архитектурной поставки

Вложены неизменённые DejaVuSans и DejaVuSans-Bold для воспроизводимой PDF-вёрстки; их оригинальная лицензия: sources/fonts/LICENSE.txt.

PDF/схемы/Markdown/JSON и скрипты сборки созданы для данного проекта. Исторические входные материалы помещены в evidence/originals.zip для аудита; это не разрешение публиковать чужие исходники.

Для сборки используются библиотеки из sources/requirements-render.txt, которые не вложены как исполняемые пакеты. Их версии зафиксированы; приложение, веса Qwen/E5, UCI dataset и OCR/AV-бинарники здесь не распространяются. Реестр фактически включённых компонентов будущего приложения заполняется по templates/THIRD_PARTY_NOTICES.template.md.
