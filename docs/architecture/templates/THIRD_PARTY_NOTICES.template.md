# THIRD_PARTY_NOTICES — шаблон

Не является финальным лицензионным реестром приложения. Заполнить фактическими версиями, revision, SHA-256, исходной licence и способом использования для каждого включённого артефакта.

Обязательные категории: JDK/Spring/React/PostgreSQL/Python libraries; scanner и signature DB; Tesseract/tessdata; E5 weights/tokenizer; Qwen GGUF/tokenizer; llama.cpp; UCI dataset/model artifacts; fonts/icons/images.

Проверенные исходные licence ориентиры: Qwen0.5B Apache2.0; E5 MIT; UCI365 CC BY4.0. Конкретные файлы/bundles должны сохранить оригинальные licence notices. Отдельно перечислить синтетические данные команды.

Смоделированы: IAM и полномочия, CRM/MDM, ФНС/ЕГРЮЛ, БКИ, кредитный конвейер и продуктовая policy, подписание и перечисление денег. Реальных финансовых операций нет.
