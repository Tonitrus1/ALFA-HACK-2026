# Соответствие требованиям кейса

Основание: кейс «Умный кредитный кабинет предпринимателя», страницы 6–11 и 13–15. Матрица отражает реализацию и границы, а не обещает полную промышленную готовность.

| Требование | Реализация / материал | Статус и ограничение |
|---|---|---|
| Веб-кабинет малого/микробизнеса | React, вход, продукты, заявки и следующий шаг | Реализовано; 2 синтетические компании |
| Связанный кредитный процесс | Draft → submit → review/RFI → решение → offer → demo complete | Реализовано; MANUAL не завершается сотрудником в текущем UI |
| Разделение скоринга и решения | CatBoost Risk + bridge + Java DemoPolicyV1 | Реализовано; BANKRUPTCY_PROXY на синтетике, искусственные thresholds |
| Сохранение данных и последовательных состояний | PostgreSQL, snapshots, версии, outbox/inbox, command journal | Реализовано; доказательства restart/recreate из исторической приёмки приведены с версией |
| GitHub с историей и версией к дедлайну | `main`, тег `submission-2026-10-26`, release | Версия сдачи — commit, на который указывает неизменяемый тег |
| Доступ экспертов | Публичный репозиторий и [demo](demo.md) | Пароли демо опубликованы с разрешения владельца |
| Docker и воспроизводимый запуск | `compose.yaml`, deploy.py, local-LLM overlay | Реализовано; первая подготовка требует интернета; требования ресурсов описаны |
| Фиксация версий | package-lock, Python locks/uv.lock, Maven BOM/pom, образы | Реализовано; не все base image tags закреплены digest, это ограничение побитовой воспроизводимости |
| README с назначением, архитектурой, конфигурацией и проверкой | [Корневой README](../../README.md), [deployment](deployment.md), [demo](demo.md) | Подготовлено для самостоятельного прохождения |
| Синтетические данные / аккаунты | Seed, датасет, синтетические финансовые наборы, company-a/company-b | Реализовано; реальные данные клиентов не требуются |
| THIRD_PARTY_NOTICES | [Корневой реестр](../../THIRD_PARTY_NOTICES.md) | Включены модели/лицензии/профили/симуляторы, включая Qwen Research и AGPL-компоненты |
| Архитектурная схема | [Архитектура](architecture.md) | Текущая система отделена от банковской цели |
| API / OpenAPI / запросы | [API](api.md), [OpenAPI](api/openapi.json), [Postman](api/potok.postman_collection.json) | Действующие routes, дополнительно внутренние AI-контракты |
| Диаграмма состояний | [Архитектура](architecture.md#сквозное-рассмотрение) | Только подтверждённый реализованный путь; зарезервированные enum описаны отдельно |
| Модель данных | [Модель](data-model.md), [inventory](schema-inventory.md) | По реальным SQL-миграциям и хранилищам AI |
| Тестовые сценарии | [Demo](demo.md), [verification](verification.md) | Основной путь, альтернативы, изоляция, сбои, persistence |
| Персональная лента и содержание | E5, preferences, cards, cursor, feedback, saved | Реализовано; bank-approved content/A-B эффект не заявляются |
| Работающий прототип | [Онлайн-стенд](https://president-diameter-endearing.ngrok-free.dev) | Реальные API, не набор статических экранов; доступность зависит от сервера и туннеля |
| Автономность от Альфа-Банка | Нет зависимости от внутренних корпоративных систем | Соблюдено; банковские интеграции отсутствуют/смоделированы |
| Независимость от платных API | Режим local с Qwen2.5 3B, core без генерации | Конфигурация реализована; функциональные локальные inference-проверки отделены от полного CPU capacity test |
| Только открытые веса LLM | Qwen2.5 3B в local-профиле | Открытые веса с Qwen Research License; коммерческая лицензия не подразумевается |
| Внутрипродуктовый сценарий | Все основные действия в кабинете | Почта/SMS/звонки не требуются |
| OCR и ассистент как дополнение | Кандидаты/подтверждение, ответы с источниками | Основной путь допускает ручной ввод; AI не подменяет решение банка |
| Enterprise-ориентированность | Сессии/CSRF/tenant isolation/версии/outbox/leases и [roadmap](bank-roadmap.md) | Архитектурные меры есть; HA, SIEM, SSO, реальные интеграции требуют внедрения |
| Исследование потребностей | Продуктовая гипотеза и спроектированные сценарии | Подтверждённый CustDev и измеренный эффект отсутствуют, не выдаются за выполненные |
| Формат загрузки и 18 МБ | PDF презентации в [presentation](presentation/) | Финальный размер проверяется перед публикацией; код/документация доступны по ссылке |

Банковское развитие и перечень недостающих компонентов находятся в [bank-roadmap.md](bank-roadmap.md). Результаты каждого фактического прогона и их условия — в [verification.md](verification.md).
