В загрузку на площадке достаточно передать PDF. Код, полный технический разбор, запуск, OpenAPI и тестовые сценарии доступны по ссылке на репозиторий внутри презентации. Версия сдачи: `submission-2026-10-26`.

Слайд «Проверки и границы MVP» убран по запросу команды. Слайды 6–7 показывают четыре результата и точные значения для проверки, слайд 11 — конкретные технологии банковского внедрения.

Оформление создано по визуальным приёмам предоставленного кейса Альфа Хак: красный, белый, крупные заголовки, простые схемы. Слайды содержат реальные экраны сервера и отдельно обозначают развитие для банка.

На опубликованном сервере при проверке 26.10.2026 ассистент работал в режиме поиска с источниками, генерация была недоступна. Это отражено на слайде 9 и в документации. Ранее проверенный локальный режим Qwen описан отдельно.

Исходник слайдов: [build_presentation.mjs](../../../scripts/jury/build_presentation.mjs). Он выполняется внутри Artifact Session с пустой презентацией. После `presentation.render({scale:2})` и экспорта PPTX скрипт [finish_presentation.py](../../../scripts/jury/finish_presentation.py) добавляет ссылки и собирает визуально соответствующий PDF с текстовым слоем. Для локального редактирования используйте готовый PPTX.
