## Как читать статусы

- **Реализовано** — есть действующий код и конфигурация.
- **Проверено** — есть конкретный воспроизводимый результат с датой и условиями. Один успешный тест не подтверждает весь модуль.
- **Экспериментально** — код доступен, но включается явно и не считается банковски валидированной функцией.
- **Запланировано** — требуется разработка или внедрение, на текущем стенде отсутствует.

## Границы решения

MVP использует синтетические компании, финансы, документы и упрощённую кредитную политику. Итоговое оформление моделируется без электронной подписи и движения денег. CatBoost оценивает синтетический `BANKRUPTCY_PROXY`, а не банковскую вероятность дефолта. MANUAL показывает передачу на дополнительное рассмотрение; рабочее место сотрудника и завершение такого рассмотрения не реализованы.

Исследование потребностей представлено продуктовой гипотезой и проектированием сценариев. Подтверждённые CustDev-интервью, измеренный бизнес-эффект, промышленная нагрузка и банковская валидация моделей в комплект не заявляются.

Старые материалы в [docs/architecture](../architecture/README.md) — историческая спецификация и источник целевых решений. При расхождении с ними для сдаваемого MVP используются текущий код, Compose и этот раздел. В частности, наличие названия технологии в прежней схеме не доказывает её подключение.
