# Результат реализации и проверки

Этот отчёт фиксирует исходную реализацию. Последующие исправления валидатора и проверка единого запуска E5 → CatBoost описаны в [отчёте интеграции](../hybrid-integration/README.md); исходные результаты и контрольные суммы ниже сохранены как история проверки.

22.10.2026, macOS arm64, Python 3.12.13, CPU. Исходная ветка `ml/feed-recommendations`, базовый коммит `0608229`. Реализация находится в рабочем дереве; commit/push не выполнялись.

Каталог расширен до 72 карточек; исходные 36 сохранены без изменения. E5 embeddings пересобраны, добавлены синтетические события, CatBoostRanker, сравнение, проверка API и контракт для backend. Полный набор и модель находятся локально в `.local/feed-synthetic-v1` и `.local/feed-catboost`; веса и датасеты не добавляются в Git.

## Закрытый синтетический тест

750 пользовательских контекстов, 6000 выдач. Модель и параметры зафиксированы до оценки test. Метрики после одинакового ограничения разнообразия тем:

| Алгоритм | NDCG@3 | NDCG@6 | Recall@6 |
|---|---:|---:|---:|
| Случайный порядок | 0,5029 | 0,4979 | 0,1105 |
| Rules | 0,8517 | 0,7648 | 0,1609 |
| Чистый E5 | 0,7078 | 0,6385 | 0,1345 |
| E5 + поправки | 0,7799 | 0,7209 | 0,1561 |
| E5-признак + CatBoost | **0,8719** | **0,7872** | **0,1694** |

CatBoost: +9,19% NDCG@6 относительно E5+поправки и +2,93% относительно Rules. 95% интервал **абсолютной** разницы NDCG@6 с E5+поправки: [0,0594; 0,0738], bootstrap по контекстам. Правила оказались сильнее текущего E5; это видно в сравнении и ограничивает ценность вывода «ML лучше baseline» без уточнения baseline.

Основной финальный отчёт: [benchmark-final.json](benchmark-final.json). `benchmark-v1.json` — первоначальный прогон той же модели, с исходным AI-черновиком содержательной разметки. После устранения повторяющихся профилей черновик переоценён; параметры модели и синтетический test не менялись. Оба варианта сохраняют статус pending_human_review. Исходный черновик сохранён рядом как историческое свидетельство.

## Устойчивость и решение о выпуске

| Сценарий | Относительный прирост NDCG@6 к E5+поправки | Вывод |
|---|---:|---|
| Базовая симуляция | +9,19% | Порог 3% и положительный интервал пройдены |
| Усиленное влияние позиции | +13,08% | Преимущество сохраняется в этом мире |
| Слабая связь профиля с интересами | +0,22% | Интервал пересекает ноль; преимущества не доказано |

Пять согласованных сценариев прошли для нового E5 и полного CatBoost. Профиль → реакции → следующая порция продемонстрирован: порядок следующей порции изменился, ранее выданные карточки не вернулись. См. [demo.json](demo.json).

**E5 остаётся по умолчанию.** В содержательной разметке нет независимого человеческого согласования. Новый контент имеет только AI_EDITORIAL_REVIEW, разметка 24 профилей — AI_DRAFT. Автоматические проверки не выдают их за человеческое одобрение. Результат на синтетике не доказывает пользу для реальных пользователей.

## Данные и обучение

- 5000 вымышленных пар user/company; 3500 train / 750 validation / 750 test без пересечения контекстов.
- 40000 запросов, 240000 выданных карточек, 324375 принятых событий.
- Для PairLogit: 17028 информативных train-групп / 54319 строк, 3599 validation-групп / 11505 строк.
- Четыре конфигурации depth 4/6 × learning rate 0,03/0,1, CPU, до 500 итераций с early stopping 50.
- Выбор по validation на наблюдаемых метках, без private truth и test-метрик. Selection NDCG@6=0,8935 относится только к размеченным показанным карточкам и несопоставима напрямую с полной oracle NDCG@6 test.
- Реальные реквизиты, финансы, исходы скоринга и скрытые параметры генератора в признаки не поступают.

См. [training.json](training.json), [data-validation.json](data-validation.json), [synthetic-manifest.json](synthetic-manifest.json), [learned-manifest.json](learned-manifest.json).

## API и производительность

Работающий loopback HTTP, 72 кандидата, 200 запросов, четыре одновременных запроса с различающимися типизированными профилями:

| Показатель | Результат |
|---|---:|
| Warm inference p95 с очисткой query cache | 33,9 мс |
| Inference p95 с готовым query cache | 1,9 мс |
| HTTP p95 | 168,7 мс |
| HTTP p99 | 190,2 мс |
| Throughput | 27,1 запроса/с |
| Cold readiness HTTP | 6,9 с |
| Ошибки | 0 |

Оба выбранных порога выполнены: warm p95 ≤200 мс и HTTP p95 ≤500 мс. Это измерение одной локальной машины, не оценка production capacity. См. [http-load.json](http-load.json).

81 тест прошёл с реальными E5 и CatBoost: контракты, offline inference, точная перестановка, короткие наборы, replay, fallback, повреждение bundle, schema/version mismatch, детерминированность датасета, связь событий с exposure, отсутствие утечки будущих реакций и разделение контекстов. См. [tests.xml](tests.xml). Есть предупреждение о deprecated alias в используемой Starlette; ошибок тестов нет.

Единая команда pipeline также выполнена на 40 контекстах с двумя стресс-наборами, без повторного HTTP: `reports/pipeline-smoke/`. Её маленькая модель не прошла критерии качества, и pipeline корректно оставил E5 по умолчанию. Это проверка всей последовательности команд, не ещё один результат качества полной модели.

Добавлен Linux GitHub Actions workflow. Его удалённое выполнение, чистая установка зависимостей и настройки branch protection в этой сессии не проверялись.
