# Feed E5 MVP — model card

Базовая модель: `intfloat/multilingual-e5-small`, revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`.
Источник и лицензия MIT: [официальная карточка закреплённой ревизии](https://huggingface.co/intfloat/multilingual-e5-small/tree/614241f622f53c4eeff9890bdc4f31cfecc418b3). [Технический отчёт авторов](https://arxiv.org/abs/2402.05672).

Модель используется без дообучения. CPU float32, 384 измерения, максимум 512 токенов, mean pooling с attention mask, L2-нормализация, префиксы `query: ` / `passage: `. Вектор карточки — только заголовок, перевод строки и полный текст; метаданные не дописываются к passage. Токенизатор и веса загружаются исключительно из локальных проверенных файлов. SHA256 указаны в `model-lock.json` и `release/SHA256SUMS`.

Запрос строится из русских шаблонов по разрешённым enum ответам и контексту. Имена, реквизиты, документы, финансовая отчётность, скоринг и причины решения не принимаются. Нет дообучения на реакциях и нет внешнего LLM при обслуживании.

После cosine similarity добавляются только коэффициенты из MVP-плана: ограниченный бонус темы и совпадение глубины. Diversification действует отдельно от оценки. Итоговая выдача не означает вероятность полезности, кредитное предложение или решение по заявке.

Проверены пять заранее записанных сценариев и их смысловые перефразировки. Основные профили дают ожидаемые темы в первой тройке. Диагностическая свободная перефразировка «закупка + стоимость» сохраняет тему закупки, но может вытеснить стоимость из первой тройки. Рабочий API принимает типизированный профиль, а не произвольные формулировки. Это ограничение отражено в отчёте, не исправляется подменой E5 или изменением согласованных коэффициентов.

Каталог и сценарии просматривал исполнитель Codex; человеческое банковское согласование не проводилось. Контент написан для MVP с общими принципами и явно вымышленными ситуациями. Нет актуальных ставок, конкретных продуктов или обещаний одобрения.

Проверки подтверждают работоспособность MVP. Реальная польза, причинный эффект реакций, A/B-преимущество, банковская пригодность и качество на неописанных профилях не оценены. Данные пользователей не сохраняются в ML.
