# Документы компании

СИНТЕТИЧЕСКИЙ ДЕМОНСТРАЦИОННЫЙ МАТЕРИАЛ. Условия вымышлены.

Для демо-продуктов используются только синтетические анкеты, финансовая отчётность, выписки и договоры. Список по продукту получают инструментом get_required_documents. Реальные персональные документы в общую RAG не загружают.
